# 1. Projektauftrag

## 1.1 Projekttitel

**Erneuerung eines 380-kV-Leistungsschalterfeldes im fiktiven Umspannwerk „UW Mitte“**

## 1.2 Ausgangssituation

Der bestehende Leistungsschalter hat das Ende seiner vorgesehenen Nutzungsdauer erreicht. Ersatzteile sind nur eingeschränkt verfügbar, und der Wartungsaufwand steigt. Ziel ist die Erneuerung des Schalters einschließlich mechanischem Antrieb, Anschlusskomponenten, Hilfsspannungsversorgung, Sekundärschnittstellen und technischer Dokumentation.

## 1.3 Projektziele

1. Austausch des Leistungsschalters innerhalb des genehmigten Abschaltfensters.
2. Einhaltung des Projektbudgets von 1.450.000 EUR mit einer zulässigen Prognoseabweichung von maximal fünf Prozent.
3. Erfüllung der definierten technischen, qualitativen und sicherheitsbezogenen Anforderungen.
4. Vollständige Übergabe der Prüf-, Revisions- und Bestandsdokumentation.
5. Sichere Wiederinbetriebnahme bis spätestens 30.09.2027.

## 1.4 Nicht-Ziele

- Umbau der gesamten Schaltanlage.
- Austausch der vollständigen Schutz- und Leittechnik.
- Veränderung des Netzschutzkonzepts.
- Erweiterung der Grundstücks- oder Gebäudestruktur.
- Reale Ausführungsplanung für eine bestehende Anlage.

## 1.5 Erfolgskennzahlen

| Kennzahl | Ziel |
|---|---|
| Terminabweichung zum Inbetriebnahmetermin | ≤ 10 Arbeitstage |
| Kostenabweichung zur genehmigten Prognose | ≤ 5 % |
| Offene A-Mängel bei Inbetriebnahme | 0 |
| Vollständigkeit der Abschlussdokumentation | 100 % |
| Arbeitsunfälle mit Ausfallzeit | 0 |
| Nicht genehmigte Scope-Änderungen | 0 |

## 1.6 Projektorganisation

| Rolle | Verantwortung |
|---|---|
| Auftraggeber | Budgetfreigabe, strategische Entscheidungen |
| Projektleitung | Gesamtsteuerung, Termine, Kosten, Risiken, Reporting |
| Fachprojektleitung Primärtechnik | Technische Spezifikation, Prüfung, Abnahme |
| Schutz- und Leittechnik | Schnittstellen, Signallisten, Funktionsprüfung |
| Einkauf | Ausschreibung, kaufmännische Bewertung, Bestellung |
| Arbeitssicherheit | Sicherheitskonzept, Baustellenkontrollen |
| Umweltschutz | Prüfung umweltrelevanter Anforderungen |
| Betrieb | Abschaltplanung, Schaltberechtigung, Betriebsfreigabe |
| Auftragnehmer | Lieferung, Montage, Prüfung und Dokumentation |

## 1.7 Entscheidungsbefugnisse

- Änderungen bis 10.000 EUR innerhalb der Reserve: Projektleitung.
- Änderungen über 10.000 EUR oder mit Einfluss auf den Endtermin: Auftraggeber.
- Technische Abweichungen: Fachprojektleitung und Betrieb.
- Sicherheitskritische Entscheidungen: Arbeitssicherheit beziehungsweise Anlagenverantwortliche.
