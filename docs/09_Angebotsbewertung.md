# 9. Angebotsbewertung

## 9.1 Bewertungsmodell

Die Gesamtwertung besteht aus einer technischen und einer kaufmännischen Bewertung.

| Bereich | Gewichtung |
|---|---:|
| Technische Erfüllung | 35 % |
| Termin und Projektabwicklung | 20 % |
| Qualität, Prüfung und Dokumentation | 15 % |
| Preis und Lebenszykluskosten | 25 % |
| Nachhaltigkeit und Service | 5 % |

## 9.2 Bewertungsskala

| Punkte | Bedeutung |
|---:|---|
| 0 | Nicht erfüllt |
| 1 | Stark unzureichend |
| 2 | Teilweise erfüllt |
| 3 | Erfüllt |
| 4 | Gut erfüllt |
| 5 | Übertrifft die Anforderung nachvollziehbar |

## 9.3 Vergabeempfehlung

Der Bestbieter ist nicht automatisch das günstigste Angebot. Eine Vergabeempfehlung berücksichtigt:

- Einhaltung aller Muss-Anforderungen,
- technische Risiken,
- Terminplausibilität,
- Qualität der Projektorganisation,
- Abweichungen vom Vertrags- und Leistungsumfang,
- Gesamtpreis und erwartete Folgekosten.

Die finale Entscheidung wird mit einer dokumentierten Nutzwertanalyse vorbereitet.
